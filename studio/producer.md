## Autonomy

**Studio merges.** Every session squash-merges its own PR once CI is green and the Critic has nothing blocking. Chosen 2026-10-23, when the producer asked for a running version as soon as possible with as little guidance as possible.

- Free, or nearly free, to run for one family.
- Get on without waiting for me: anything that needs me is an ask with a default (2026-10-23).
- PR titles are conventional commits, `type(scope)!: Summary`. PRs are required on `main`; merge with squash.
- The Realtime Trains token never goes in the page, the repo or a URL: only the Worker's secrets.
