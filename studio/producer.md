# The producer

Your settings, the rules you've given the studio, and what it has learned about how you use the site. The Director keeps it, and you can correct it any time with `/director`. Changes to this file wait for you.

## Autonomy

**Studio merges.** Every session squash-merges its own PR once CI is green and the Critic has nothing blocking. Chosen 2026-10-23, when the producer asked for a running version as soon as possible with as little guidance as possible.

## Standing rules

- Free, or nearly free, to run for one family.
- Get on without waiting for me: anything that needs me is an ask with a default (2026-10-23).
- PR titles are conventional commits, `type(scope)!: Summary`. PRs are required on `main`; merge with squash.
- The Realtime Trains token never goes in the page, the repo or a URL: only the Worker's secrets.

## Taste notes

What the studio has learned from your feedback, each with where it came from.

- The point is not standing around for 25 minutes with a child, and not arriving just as one goes by: [the notes](https://github.com/thesnwmn/notes/tree/main/too-too-soon).
- The site should have character: fun for children, and obviously about trains (a steam-train logo, a word mark): the producer, 2026-10-24, via /director.
- Setting up a spot shouldn't need railway codes: search by name, and a spot can be a single station: the producer, 2026-10-24, via /director.
- The map picker must not depend on a busy free server answering at the moment you tap: the producer, 2026-10-24 ("The map view has never worked for me").
