# Direction

Where the site is going now. The Director keeps it, and changes to it wait for the producer.

## Now

[m1-first-trains](milestones/m1-first-trains.md): a free, running site that lists the next trains past a spot, with countdowns, usable on a phone at the bridge.

## Priorities

1. Running and useful as soon as possible: the list with countdowns, live, before anything clever.
2. Then easier to set up: a map to pick the spot, instead of typing timing point codes.
3. Then more accurate: "it's here!" taps that learn each spot's offsets.

## Off the table

- Anything that costs money to run, unless the free Realtime Trains plan turns out not to include passing trains.
- An always-on server (the Network Rail feeds): only if Realtime Trains isn't enough.
